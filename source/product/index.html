DUIX 数字人智能前台是一套可在政务大厅、医院导诊、大型场馆等场景中立即可部署的 AI 数字人交互系统——访客通过 Android 终端与 3D 数字人对话，获得办事指引和材料清单；遇到复杂问题时自动生成编号引导至人工窗口，实现人机闭环。

我们的做法有何不同？

不是替代人工，而是让人工做更有价值的事

✅ DUIX 智能前台
● 软硬一体，单机可运行，无需改造基础设施
● 上传文档即用，后台实时修正反馈闭环
● 知识库回答 + 编号引导窗口办理
● 数据私有化部署，客户持有全部数据
● 千元级 Android 设备即可运行
❌ 竞品普遍做法
● 需上云、对接、定制开发，周期长
● 需专业团队标注训练，维护成本高
● 纯粹替代或纯粹人工，缺少过渡态
● 依赖公有云平台，数据合规风险
● 专用硬件或固定大屏，成本高

常见问题

没有网络能用吗？
核心知识库问答运行在本地，不依赖外部网络。仅 LLM 调用需要 API 访问（可配置内网模型）。
数字人形象可以定制吗？
可以。DUIX SDK 支持更换数字人模型，可根据客户品牌定制。
访客需要安装 APP 吗？
访客在 Android 终端（平板/一体机）上使用即可。也可提供 APK 让访客自行安装到手机。
与现有业务系统能对接吗？
提供 HTTP API 接口，支持对接叫号系统、业务系统等第三方系统。标准化集成约 1-3 天。
数据安全怎么保障？
全部数据存储在客户私有服务器，不上传任何第三方平台。可签署数据保密协议。
回答错误怎么办？
管理员在后台点「修正」→ 修改内容 → 自动重写知识库，下次同类问题用正确回答。
