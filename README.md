Golook 是一个专注于 **AI/LLM 技术**、**效率工具** 和 **深度分析** 的中文技术博客，由 Hexo 静态站点生成器构建，部署在 EdgeOne Pages 上。

## 站点

| | |
|---|---|
| **网址** | [golook.cf](https://golook.cf) |
| **主题** | NexT 8.27.0 (Pisces 双列布局) |
| **语言** | 中文 (zh-CN) |
| **写作** | Markdown + Hexo |
| **托管** | GitHub → EdgeOne Pages 自动构建 |

## 内容方向

- 🤖 **AI/LLM 技术** — 模型原理、架构对比、Prompt 工程、Agent 实践
- ⚡ **效率工具** — 开发工具链、自动化脚本、CLI 工具测评
- 📊 **深度分析** — 开源项目解读、技术选型指南、架构设计

## 本地开发

```bash
# 安装依赖
npm install

# 本地预览
npx hexo server

# 生成静态文件
npx hexo generate

# 部署
npx hexo deploy
```

## 技术栈

- **Hexo 7.3.0** — 快速、简洁的静态站点生成器
- **NexT Pisces** — 优雅的 Hexo 主题，支持中英文
- **EdgeOne Pages** — 腾讯云边缘部署平台，Git 触发自动构建
- **hexo-excerpt** — 首页自动生成文章摘要
